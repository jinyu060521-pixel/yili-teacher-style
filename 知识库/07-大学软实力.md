# 知识库 · 大学软实力

> 来源：《大学软实力构建提升课》（课程转录，约2.7小时，2026-07-25）

## 核心观点

1. **软实力比技术课重要**：大学四年做什么，比录取进什么大学、什么专业重要100倍；Python、AI没学好都可以慢慢来，但沟通、答辩这类场景充斥整个大学生活，决定你能拿到什么资源。
2. **共情能力是一切沟通的底层**：以对方的理解能力为基础输出，时刻思考"对方正在想什么、期待什么"。这也是与AI协同办公最重要的能力——好的提示词工程就是替对方把背景交代清楚。
3. **场景与心态要匹配**：不能用说服的心态去辩论，不能用辩论的心态去演讲；每个场景有且只有一个正确的玩法。
4. **答辩公式**：答辩 = 80%演讲 + 20%说服 + 0%辩论，核心是"只答不辩"。
5. **心法四句**：世界是个巨大的草台班子；迷茫就对了；Nothing really matters（人生容错率大到超乎想象）；大大方方去丢脸。

## 场景方法论

### 场景一：拒绝
- **方法A（塑造第三方白脸）**：拿出第三方理由拒绝——"不是我，是第三方原因导致今天干不了"。他自己存好"正在出差/开车"的视频，遇事就发。反面案例：好兄弟江藩借口"被辅导员叫走"，结果被他在宿舍一楼路过时抓包打游戏——用了要演像，别翻车。
- **方法B（他真正推荐的）**：直接拒绝。"我忙，我不想干，拜拜，又如何呢？哪有那么多人情世故？"先想想能不能直接拒绝。

### 场景二：演讲 / 班委竞选
- **一句话法则：满足被演讲者的预期身份**。上台前想明白：你是来干嘛的，台下的人对你的预期是什么。
- **台下人心态分析**：竞选班委时台下同龄人的真实心态是"I don't give a shit"——谁当班长跟他没关系。演讲的全部任务是把"投你"变成"有意于我"。
- **一句话赢竞选（他当年当班长的原话）**："如果今天依力当选了班长，全班所有同学每一个人的事情就是我的事情。"
- **班委战略价值**：①信息获取密度与别人完全不同（奖学金、竞赛、志愿者信息最快最密）；②被逼到定位上，天然被迫积极、被迫沟通——不会"泯然众人矣"。
- **精力观**："人的精力是没有上限的"（他一天睡6小时连轴七天）。

### 场景三：辩论
- 推荐打辩论赛（尤其新生赛），要的不是口才，是**辩证思维**。训练案例：求是辩论队让新人用一周论证"杀人是正确的"，逼你颠覆固有观念找细分切口立论。
- **辩论的本质**：辩题没有对错，双方辩的不是真理而是"我怎么比你更对一点"；**辩论是给观众和评委看的——要说服的不是对面，是观众**。
- 实操案例：他持"小城市一间房"一方，对方历数大城市教育医疗机会，他一句话终结："对方辩友，这些东西跟您有什么关系呢？您这还是一张床吗？"
- 一句话：关注裁判，不要被对方抬杠。

### 场景四：说服 / 谈判
- **原则：让对方尽可能舒服地做选择**（利他心理）。
- **完整案例（砍价5000→2000）**：社团请外包开发软件，预算2000对方开价5000。步骤：①真诚爆预算上限，报1500（留300缓冲）；②抬高对方——"第一次合作、你们不差这钱，我们社团日后无条件帮你们"；③不逼对方当场选择，提议休会5分钟各自讨论；④回到谈判桌先说话：有老师愿意加500，预算变2000，"希望你们帮我们一个忙"——成交。
- **心法**：对方不缺钱，5000块代表的是身价；无法让步时用情绪价值补足差价——让对方觉得是"施舍"是"帮一次"而非降价掉价。

### 场景五：答辩（课程落点，篇幅最大）
**如何讲（含PPT）**：
- 不要成为PPT的奴隶——PPT不是拿来念的，是梳理逻辑、让台下人跟着你的逻辑走。
- 心态关："各位老师，我就是个菜鸟，我就做了这么点东西，但至少我尽力了。"逻辑支撑：项目本质是有限时间精力知识面下压榨出有限的东西锻炼思维。
- 先让自己信，才能让别人信；适度用过往经历包装自己（不是造假）。案例：二次选拔自我介绍——"我在暑假自学了从线性神经网络到多层感知机、CNN、RNN、LSTM到Transformer的全部底层原理，并能手动实践出几个项目——哥们，你不赢谁赢。"
- 学术答辩PPT规则：整体偏素；**每页不超过50字**；布局有逻辑感（讲底层就把底层放画面下方）；巧用显示/消失动画推进逻辑；最后一页不放"谢谢"，放**整场答辩的浓缩大纲**（提问环节老师会看着大纲提问）；形成自己的PPT模板（左侧随页切换的目录，观众随时知道全局位置）。
- 例外：商赛/创赛PPT本身就是作业，用论文风格、信息密度高，但图表必须规范。

**如何答**：先听懂老师真正问什么；**直接回答，不要绕**，能用一句话总结就一句话。案例：无人机电池续航12小时被质疑"够吗"——正确答法："续航确实是我们没有花大精力解决的致命点，以后会探索更好的方案。"不要沉默。

**如何辩**：**只答不辩**。台下的人过去50年都在研究这个，你不比他聪明；除非老师说的确有事实出入，否则承认问题、表示改进即可，不要教老师做事。

## 案例与数据备忘

- 砍价谈判：预算2000 vs 开价5000 → 报1500 → 休会5分钟 → 2000成交（求是潮外包）。
- 每页不超过50字（学术答辩PPT）；答辩典型配置：5分钟陈述+10分钟提问。
- 无人机电池48V磷酸锂续航12小时被质疑、四人干两个月颗粒无收（反面案例）。
- 他自称"浙大第一大辩人"：SRTP智能导航小车凭答辩拿特等奖；Ocean Waze节能减排全国决赛；贝恩商赛Health Mirror项目。
- 全球塑料年产量近8亿吨仅9%回收，2050年海洋塑料将多于鱼类（答辩开场数据）。
- 结尾价值观输出顺序：草台班子 → 决策先拿信息 → 多去经历无问西东 → 迷茫就对了 → Nothing really matters → 大大方方丢脸 → 控制情绪（让杏仁核知道谁才是老大）→ 保持真诚 → 多运动。
