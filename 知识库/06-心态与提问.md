# 知识库 · 心态与提问

> 来源：依问三不知《大一防焦虑指南：绩点主线+活动建议》《大学如何获取前辈的经验？你必须学会的提问艺术！》
> 用法：讲授"大一规划/防焦虑/向上社交/提问求助"话题时使用。

## 核心观点

1. **大学里要做的，未必要大一做**：竞赛、进组、实习都超出大一能力范围，"如果只混了一个名头而没有实质内容，这段履历在未来的考核中其实没有什么含金量"。
2. **大一的主线是绩点**：①难度低（学分高、考试占比大，出分区间拉得开）；②复利效应强（转专业、进组、进项目组打比赛，看的都是绩点）。"70%的同学第一年的绩点排名和大三下学期的绩点排名是一致的。"
3. **大一成绩差也能绝地翻盘**："每个学校每个专业冲到前几名外保清北的，有很多是大一浪过头、绩点倒数的同学。"
4. **你99%的问题可以通过信息检索得到答案，只有1%值得向人类提问。**
5. **最好的感谢是报喜**：不推荐买礼物（对方有心理负担），一个月半年后回来报喜"你帮我的那个坎我迈过去了"，对前辈来说比什么都值。

## 方法论

### 大一防焦虑路线图

- **大一上学期**：可以几乎不参加任何活动，先all in课内，等第一次成绩出来就有参照系，再根据排名决定下学期策略；
- **大一可以做的**：学生工作、志愿服务、讲座（认识专业、认识学校、看看自己愿意长期做什么）；
- **大一不要为竞赛/科研/实习丢绩点主线**："与其一开学就把精力分给五六件事情，不如先把课内的事情做好。"
- **大二大三分野**：找对方法、面向课程考核标准去学，"使劲学，不怕丢脸地学"，有机会绝地翻盘。

### 提问艺术（四条）

1. **补全上下文**："大学中没有绝对正确的决策，只有目前看起来最适合你的决策。"提问要带上自己的背景（绩点排名、已有学生工作、论文情况），让对方用最省力的方式判断。举例："学长，我绩点排名15%，听说某校推免卡10%，能不能给我推荐给分好的课程？"
2. **展示你的卡点**：先做充分调研（经验帖、微信搜一搜、视频教程），再带着调研结论来请教。"没有人喜欢一个连基础概念都不清楚的提问，我们都反感当别人的豆包。"让对方的回答从"从零捋逻辑"变成"在你调研基础上给你一个准话"。
3. **报喜是最好的回报**：及时进度汇报和结果报喜。
4. **别逮着一个人使劲薅**：除了亲爹妈，别人对你的帮助都属于义务劳动；不同问题找不同的人。

## 金句

- "大一的课看起来基础，却是你干扰最少、最容易把成绩拉高的一年。"
- "一个是守成，一个是攻城，难度完全不一样。"
- "不要着急在第一年去证明自己，否则反而会适得其反。"
- "如果他们对你本身的人生没有任何兴趣和窥探欲，也不会审判你的情况，提供更全的背景只是为了更好地定位你的问题。"
- "你已经在自己的能力范围内充分调研了，但还有困惑——那这个问题就该拿去请教。"
- "如何在短时间内成为任何一个领域的小专家，是我接下来要教你们的最重要的能力。"

## 给skill的使用建议

大一学生来问规划，先问"第一次成绩出来了吗"，没出来就劝先all in课内；学生问"要不要参加XX活动"时，用"主线思维"判断（含金量+是否超出当前能力）；教提问时逐条演示"差提问vs好提问"。
