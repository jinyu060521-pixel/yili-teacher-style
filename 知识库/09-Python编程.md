## 分节知识点

### 第01节（视频05）· Python入门
- 计算机原理：计算机只认识0和1，0和1本质是芯片里的高低电平；十进制转二进制→电脉冲信号→电路运算→转回十进制，"电信号由此产生了逻辑"。
- 编程语言=翻译工具：人写高级语言，层层翻译成机器能懂的指令。
- 算法概念：99枚硬币找最重（天平二分）、100颗钻石选最大（最优停止）、2026层台阶扔瓶子（临界台阶）。算法=面向具体问题，在数学模型上给出解决方案、找最优解。
- 互联网岗位分工：前端、后端、UI、算法、测试。
- Python特点：代码简洁、缩进代表代码块、动态类型、解释执行、跨平台、集成能力强（CV2底层是C++）、生态丰富（Pandas/NumPy、Django/Flask/FastAPI、量化金融、抢票脚本）。
- 环境搭建：VSCode + Code Runner插件。
- 讲法/口诀："人生苦短，我选Python"——不要把时间耗在性能优化和类型定义上。

### 第02节（视频06）· 数据类型与字符串
- 数据类型全景：int、float、complex、str、list、tuple、set、dict、bool、NoneType；type()和isinstance()判断类型。
- int整数：Python动态语言按需分配存储；C语言要事先指定位数。
- 表达式vs字面量：2*3是表达式输出结果6；引号引起来的是字面量原样输出。
- 字符串：单/双/三引号；空格也算字符；字符串里放引号要换引号种类。
- 格式化占位符：%d、%f；%.2f控制精度（"开局屠龙刀一刀999.9998伤害，%.2f输出10000.00——诈骗，这游戏绝对是诈骗"）；m.n控制宽度精度。
- if条件判断：区间判断要写"money>=1000 and money<=5000"，不能写成数学连写式。
- float精度15-17位 vs Decimal无限精度：财务/货币用Decimal；"float用于精度不高的99%的场景"。
- 讲法/口诀："C是非常严格的父亲"；"引号引起来的就是字符串"。

### 第03节（视频07）· 循环与函数
- while循环：务必检查终止条件（count+=1），否则死循环；无限循环在需要时有用（嵌入式最外层loop、抢票脚本）。
- 抢票/自动化脚本：务必设置延迟（random 1-3秒伪装成人在操作），换IP让请求"来自全国各地"。
- random库：randint闭区间、randrange前闭后开。
- for循环：for letter in "hello"逐个取出；"遍历就是扫过一遍"；range()常与for搭配。
- 循环变量作用域：循环变量只用于循环内；循环里尽量用item。
- 函数：def定义、return返回；return之后函数结束；不写return与return None等价；函数嵌套调用；递归（Fn=Fn-1+Fn-2）。
- 多返回值：本质返回元组，解包接收（squared, cube = multi_return(88)），"有多少个返回值就用多少个值接收，顺序要对"。
- 传参方式：位置传参、关键字传参（参数多时位置传参容易忘顺序）。
- 回调函数callback：把自己的函数传进去，对方执行完后调用你的函数；进度条案例（end="\r"覆盖输出）。
- 讲法/口诀："前取后不取"（randrange 0到10，0可能返回、10一定不返回）；"字符串是字符的串串"。

### 第04节（视频08）· 列表、切片、集合与字典
- 列表list：中括号定义；下标从0开始、最后一个n-1；负数下标（"只要有下标就有负下标"）。
- 字符串本质：字符的数据容器=用引号表示的列表，也有下标、也能len()、count()。
- 字符串不可修改：重新赋值是改变变量的值，不是修改字符串里的字符。
- 切片：倒序[::-1]；省略代表从0开始/到最后；前取后不取。
- 算法回顾：二分法、冒泡排序、递归、贪心；"电子信息、电气专业以后学的最优规划本质就是贪心算法"。
- 字典dict：键值对key:value，通过key精准找到value；遍历用for key, value in d.items()（"这是你这辈子会写下无数次的代码"）。
- 五大容器对比：列表/元组/字符串（序列）支持下标；集合字典不支持重复；len()全部通用。
- 讲法/口诀："通过key找到value，就是字典"；"叶子节点——叶子上面不会再生根发芽了"。

### 第05节（视频09）· 异常处理、类与对象、模块与爬虫
- 异常处理try/except：捕获指定异常类型、as e接住异常对象、多except分支。
- 异常传播：内部函数出错，所有调用它的函数均出错，一层层向外传递（"工厂流水线生产，一步错步步错"）。
- 类与对象：__init__构造方法自动执行；self定义时必须写、调用时忽略；点操作符访问类内属性与方法。
- 继承：子类继承父类所有属性方法；重写__str__（print华为=开屏界面、print iPhone=苹果标识）。
- 模块与库：文件夹放__init__.py就变成库；包内可套包；import math vs from math import sqrt。
- 爬虫入门：浏览器右键检查、元素面板定位；B站视频下载器案例：库失效就"换库"，找三天前还在更新的别人维护好的库。
- 讲法/口诀："先定义再使用"；写库"简单啊，Easy"；函数=输入-处理-输出。

### 第06节（视频10）· 信息学速通（上）：代码逻辑
- 课程定位：强基计划校测笔试的信息学内容速通，面向无竞赛基础同学。
- 二进制与字节：short占2个字节所以范围-32768~32767；int/long/long long区别是范围不同。
- C++数组：int a[5]定义时标明类型；下标从0开始；能看懂伪代码即可。
- 运算符：%取余、//整除；7/2在Python输出3.5，在C++输出3。
- 程序执行流程：顺序、分支、循环；程序流程图。
- 条件判断：成绩>=60及格；判断奇偶n%2==0；一个等号是赋值、两个等号才判断相等。
- 函数思维：输入、处理、输出；调用时不用关心内部如何运作；函数名要有意义。
- 求最大值算法：用m记录"见过的最大的值"，遍历比较替换——这就是max函数的实现方式。
- 算法定义与优化："算法是用更好的数学思维和更好的数学方法来优化现实世界中存在的问题"；暴力匹配两大问题（效率低、每次失败从头开始）；KMP算法（利用已匹配信息，只理解思维）。
- 讲法/口诀："C++=对类型特别严格的一个父亲"；while="当"（读代码时脑内要有声音）。

### 第07节（视频11）· 信息学速通（下）：数据结构与算法思维
- 栈stack：后进先出LIFO、push/pop、只操作顶部；考题会换包装（波兰表达式），识别出"后进先出"就知道是栈——"考的是思维"；队列=先进先出FIFO。
- 波兰表达式：中缀/前缀/后缀三种；前缀从右往左读、后缀从左往右读，数字压栈遇运算符取出运算。
- 二叉树：根节点、深度、父节点与子节点、叶子节点；每个节点最多两个孩子。
- 哈希表：hash function根据字母数量算出存放位置；冲突处理三招（新数据顶掉旧位置、同位置放数组、加if规则）；"空间换时间"。
- 图graph：顶点和边、网状关系；微信好友关系就是图；无向图/有向图/带权图；解决城市交通、社交推荐、网络分析；"数是图的特殊形式"。
- 时间与空间复杂度：往往矛盾；算法优化是在两者之间找平衡。
- 暴力枚举的极限：3个城市6种、10个360万、20个21亿、50个"超过宇宙原子数，算不出来的"。
- 递归：跳台阶jump(n)=jump(n-1)+jump(n-2)；必须规定出口（n==1、n==2）。
- 贪心思维：把2025拆成若干互不相同的正整数使乘积最大。
- 随机化算法：不公平硬币掷两次——两正或两反无效重来，正反你赢、反正我赢，双方公平。
- 扔瓶子问题：2026层台阶有限瓶子找临界层；理论下界：无论多少瓶子都不可能少于11次。
- 讲法/口诀：栈="后进先出"；图=微信好友关系。

### 第08节（视频12）· 抢占AI时代的大学先机
- AI发展脉络：1943年MP模型（最早的神经网络模型）；神经元=轴突+突触模拟；神经网络本质是拟合函数。
- AI关键节点：1989卷积网络、2012 AlexNet、GAN（AI给自己制造错误样本丰富训练集）、2018 BERT/GPT-2、2020 GPT-3（提出Prompt概念——你给的示例让模型明白要干什么）、2024.5 GPT-4o多模态、2024.9深度思考、2024.12 Sora文生视频。
- MCP协议："AI时代的USB接口"，标准化AI与外部工具、数据、业务系统的连接。
- Vibe Coding：2025.2起；人不再逐行写代码，用自然语言描述想法让AI生成代码，再对话试错调整；三阶段：传统编程→AI辅助编程→vibecoding；"人类写代码是非常反人类的过程"。
- AI的记忆机制：AI会在休息时间进入"做梦模式"，回忆对话、删不重要信息、保留最重要的来记住你。

- 工具与硬件：Gamma.app做PPT排版；多传感器融合（国产车摄像头+激光雷达双保险 vs 特斯拉纯视觉）。
- 大学电脑选购：便携性最重要（大一买XPS15"巨重"的教训）；不建议台式；二手Mac M芯片便宜；打不打游戏决定买什么。
- 讲法/口诀："机器本来就应该是我想干嘛它就干嘛"；AI能力上限"仅仅只是算力和电力"。
