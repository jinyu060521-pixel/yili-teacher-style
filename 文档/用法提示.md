# 依力老师风格包 · 用法提示

## 三选一，30秒上手

### 1. Claude 用户
把 `依力老师风格-完整版.skill`（或轻量版）文件拖入 Claude 一键安装。之后在任意对话里直接说：

- "用依力老师的风格讲：大一要不要进课题组？"
- "用依力老师的风格给我讲什么是梯度下降"
- "依力老师会怎么回答：考研失败怎么办？"

### 2. 用 GPT / 豆包 / Kimi / Codex 等
把 `.skill` 文件（或解压后的 `SKILL.md` + `知识库/`）上传给 AI，说一句："按这个来，用依力老师的风格讲XX"。
不方便传文件时，粘贴 `依力老师提示词-通用版.txt` 的内容，效果相同。

### 3. 不玩 AI
直接读 `知识库/`——实习、进组、竞赛、面试、论文、心态提问的攻略都在里面；
想学讲课风格的，读《风格手册》《金句库》《示例课》。

## 两个版本的区别

| | 完整版 | 轻量版 |
|---|---|---|
| 说话风格 | ✅ | ✅ |
| 依力老师知识库（9个主题） | ✅ | ❌ |
| 适用场景 | 想听他"怎么说"也想知道他"怎么答" | 只想模仿说话方式 |
| 大小 | 36KB | 5KB |

拿不准就发完整版。

## 微信/QQ传输注意事项

- 部分聊天工具会拦截或改名 `.skill` 后缀的文件。如果对方收到后打不开：
  1. 优先发送 `依力老师风格包.zip`（解压后整个文件夹可用）；
  2. 或让对方把文件后缀从 `.zip` 改回 `.skill` 再打开；
  3. 实在不行，把 `SKILL.md` 和 `知识库/` 的文本内容直接发给对方即可，效果一样。
- 微信群发长文本容易被折叠，建议：文案一段话 + 文件一个，不要连续刷屏。

## 小提示

- 完整版回答大学/AI/Python问题时会优先用依力老师本人的真实方法论，不会瞎编；
- 风格浓度想调？在对话里说"口头禅再少一点/多一点"就行；
- 效果不满意时补充一句："更像依力老师一点，多点'对不对'，多点场景还原。"
