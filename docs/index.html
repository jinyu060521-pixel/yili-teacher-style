这是什么

这个项目把他的说话方式和教学方式做成了可复制的风格包——装进Claude，AI就用他的口吻给你讲课答疑；不只风格，他讲过的实习、进组、竞赛、面试、论文、提问、AI原理、Python，也整理成了9份知识库，回答用的都是他本人的真实方法论。
