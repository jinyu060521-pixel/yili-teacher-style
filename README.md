# 依力老师风格包

把一门 **45 小时大学 AI 课程的讲课风格**，蒸馏成可安装、可复制的 AI 技能与知识库。

[依力老师](https://space.bilibili.com/依问三不知)（B站：依问三不知，浙大控制+竺院创业强化班）讲课风格鲜明：口头禅"对不对"（全语料出现 **1483 次**）、称呼"各位同学/兄弟们"、用真实大学故事讲道理、"场景还原"+"一句话法则"两大教学装置、"在你心中埋下一个种子"的教学理念。

本项目把 116 万字语料蒸馏成：**1 个整合 skill（风格+知识库）+ 9 份知识库 + 配套文档 + 一个单文件官网**。

## 快速开始

| 你想要什么 | 用这个 |
|---|---|
| 让 Claude 用他的风格讲课 | `dist/依力老师风格-完整版.skill`（一键安装）或 `SKILL.md` |
| 只想学说话方式，不要知识库 | `dist/依力老师风格-轻量版.skill`（`轻量版SKILL.md`） |
| 用 GPT / 豆包 / Kimi 等任何 AI | `dist/依力老师提示词-通用版.txt`，一段话粘贴即可 |
| 不玩 AI，直接读干货 | `知识库/` 9 份攻略 + `文档/` 风格手册、金句库、示例课 |
| 全部拿走 | `dist/依力老师风格包.zip` |

安装后对话示例："用依力老师的风格讲：大一要不要进课题组？"、"依力老师会怎么回答：考研失败怎么办？"

## 仓库结构

```
├── SKILL.md                    # Claude skill 核心（风格+知识库索引，完整版）
├── 轻量版SKILL.md              # 纯风格版
├── 知识库/                     # 9个主题：实习/进组/竞赛/面试/论文/心态/软实力/AI原理/Python
├── 文档/                       # 风格手册、金句库（59条）、示例课（3篇）、用法提示
├── dist/                       # 打包产物：完整版/轻量版 .skill、zip、通用提示词
├── docs/                       # 官网（单文件，下载已内嵌，GitHub Pages 直接可部署）
└── 发布指南.md                 # 如何推送到 GitHub 并开启 Pages
```

## 官网与下载链接

`docs/index.html` 是单文件官网：黑板+粉笔的设计，四个下载按钮的文件已**内嵌进网页内部**，双击本地打开也能下载。

开启 **GitHub Pages**（Settings → Pages → Source 选 `main` 分支 + `/docs` 目录）后，`https://<你的用户名>.github.io/<仓库名>/` 就是你的永久下载链接。

更新 `dist/` 里的文件后，运行 `docs/rebuild.py`（或双击 `docs/更新网站.command`）即可把新文件重新内嵌进官网。

## 蒸馏方法

1. 19 个课程视频约 45 小时 → 音频切分 546 块 → Whisper 语音转文字 → 116 万字带时间戳转录稿；
2. 全量语料统计（口头禅词频）+ 逐课分析 → 风格画像；
3. 课程知识 + 依问三不知 B 站视频 12 篇 → 主题知识库；
4. 画像压缩为 SKILL.md 操作规则，知识库作为观点来源 → 示例验证。

统计口径示例："对不对"1483次（约33次/小时）；"各位/各位同学"1949次；"举个例子"157次；"OK"463次；"Do you understand?"65次。
